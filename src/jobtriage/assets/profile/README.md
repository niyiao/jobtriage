This folder holds the person: RESUME.md and DETAILS.md — what an
agent reads for your details (use the resume PDF only for uploads) —
and the resume PDF itself.

`DETAILS.md` starts as a blank template with the headings agents use;
fill it in through the `setup` skill or by hand. Add `RESUME.md` and
`resume.pdf` yourself; `jobtriage init` does not overwrite them.
